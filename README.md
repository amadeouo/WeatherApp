# Weather App — Приложение погоды

![Design preview for the Weather app](./preview.jpg)

Современное веб-приложение для отслеживания погоды, построенное на стеке React + TS + Vite

## 🚀 Стек технологий

- **Фреймворк:** [React 19](https://react.dev/)
- **Сборка:** [Vite](https://vitejs.dev/)
- **Язык:** [TypeScript](https://www.typescriptlang.org/)
- **Стилизация:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Управление состоянием:** [Zustand](https://zustand-demo.pmnd.rs/)
- **Компоненты:** [Shadcn](https://ui.shadcn.com/) + [Lucide React](https://lucide.dev/)
- **Роутинг:** [React Router 7](https://reactrouter.com/)
- **API:** [Open-Meteo API](https://open-meteo.com/) (бесплатное API, не требует ключа)

## ✨ Основные возможности

- **Поиск локаций:** Удобный поиск городов с использованием Geocoding API.
- **Текущая погода:** Отображение температуры, влажности, ощущаемой температуры, скорости ветра и осадков.
- **Прогноз:**
  - Почасовой прогноз на выбранный день.
  - Прогноз на 7 дней с минимальной и максимальной температурой.
- **Настройки:** Переключение между метрической и имперской системами единиц измерения.
- **Адаптивность:** Полная поддержка мобильных и десктопных устройств.
- **Состояние:** Сохранение выбранных единиц измерения и локации в LocalStorage.

## 📂 Структура проекта (папка frontend)

Проект организован по модульному принципу:

- `src/app`: Инициализация приложения, глобальные стили, провайдеры контекста и роутинг.
- `src/pages`: Основные страницы приложения (Главная с погодой, 404).
- `src/widgets`: Крупные блоки интерфейса (Header, Hero).
- `src/components`: Переиспользуемые UI-компоненты и логические блоки (поиск, карточки погоды).
- `src/store`: Глобальное состояние приложения на Zustand (погода, поиск, геопозиция, настройки).
- `src/utils`: Вспомогательные функции, хуки и трансформаторы данных.
- `src/types`: TypeScript интерфейсы и типы.
